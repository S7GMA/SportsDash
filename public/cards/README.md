# Card portraits (overwrite to replace)

Name files after the **athleteId** (same id the app already uses):

| Example file | Used for |
|---|---|
| `max_verstappen.png` | Max Verstappen |
| `norris.png` | Lando Norris |
| `lebron-james.png` | LeBron James |
| `shohei-ohtani.png` | Shohei Ohtani |
| `bryce-harper.png` | Bryce Harper |

Supported extensions: `.png` `.jpg` `.jpeg` `.webp`

Just overwrite the file with the same name — refresh the app. Local files always win over remote URLs.
